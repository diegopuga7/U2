# A3. Caza los errores

## Errores encontrados

1. Falta la declaración `<!DOCTYPE html>` al principio.
2. Falta el atributo de idioma en `<html>` (`lang="es"`).
3. Falta `<meta charset="utf-8">` en el `<head>`.
4. La etiqueta `<title>` **no está cerrada** (falta `</title>`).
5. El `<h1>` se cierra con `</h2>`: la etiqueta de cierre no coincide.
6. Anidación incorrecta: `<b>` se abre dentro de `<p>` pero se cierra **después** de `</p>`.
7. Falta `<meta name="author">` con el nombre del alumno.

## Versión corregida

```html
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="utf-8">
<meta name="author" content="Tu Nombre">
<title>Mi tienda de gadgets</title>
</head>
<body>
<h1>Ofertas de otoño</h1>
<p>Auriculares con <b>cancelación de ruido</b></p>
</body>
</html>
```
