# A4. Estilos rotos

## Línea 1

**Qué falla:** falta el `;` que separa las dos propiedades.

```html
<h1 style="color:red; font-size:40px;">Directo esta noche</h1>
```

## Línea 2

**Qué falla:** dentro de `style` se usa `:` y no `=` entre propiedad y valor.

```html
<p style="text-align:center;">Estreno de temporada</p>
```

## Línea 3

**Qué falla:** el párrafo se cierra con `<p>` en lugar de `</p>`.

```html
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica</p>
```
